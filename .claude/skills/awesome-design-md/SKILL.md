# Awesome DESIGN.md

Each folder in `brands/` holds a `DESIGN.md` that describes one brand's visual language:
palette, typography, spacing, layout, components and rules.

How to use:
1. List `brands/` and pick the brand the user named.
2. Read `brands/<brand>/DESIGN.md` before writing any UI.
3. Apply the design *language* (spacing, type scale, color logic, component shapes).
   Do not copy the brand's logo, trademarks or product names onto a page that could be
   mistaken for the real company's site - use the user's own product or a fictional one.
